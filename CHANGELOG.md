# Журнал изменений

## 1.0.0 — 29 октября 2026

**Выпуск**
- Автообновление: раз в день, если вы разрешили, Oddments проверяет новую версию на GitHub и показывает тост «Есть новая
  версия» — «Установить» скачивает, ставит и перезапускает. Обновления подписаны ключом проекта.
- Окно первого запуска: язык, папка библиотеки, перенос из Eagle, ИИ-поиск, текст на картинках, обновления, «Без сети».
- Настройки › «О программе»: версия и обновления, приватность, отчёт о сбоях, лицензии.
- Режим «Без сети»: одной галкой — ничего не скачивается и не отправляется, окно не загружает ничего с сайтов.
- Локальный отчёт о сбоях: ошибки и сбои пишутся в файл на компьютере, «Скопировать отчёт» — без личных путей; никуда
  не отправляется.
- Перенос из Eagle (папки, теги, заметки, ссылки, даты; повторный перенос добавляет только новое) и картинок с досок
  PureRef.
- Лицензия MIT и полный список сторонних компонентов с текстами лицензий — в приложении и в `THIRD_PARTY_NOTICES.md`.
- Документация на русском и английском: установка, приватность, перенос, сборка, подпись, выпуск.

**Новое после 0.1.0**
- Гауссовы сплаты: просмотр PLY и SPZ, миниатюры, «Сплат из модели», сплат в качестве Cycles через аддон Blender 1.21.
- «Убрать фон» моделью BEN2 на видеокарте: край по фото, очистка каймы, кисть.
- Лупа за курсором в «Увеличить» и «Убрать фон».
- Английский интерфейс там, где его не было, числа и даты по-английски.
- Правки по аудиту интерфейса: раскладка панели свойств, плотное стекло под текстом, вкладки по ширине ряда, меню
  карточки короче, выбор файла для инструментов из палитры, клавиши B и U, доступность с клавиатуры.

## 0.1.0 — 28.10.2026

Первый публичный выпуск: библиотека референсов для Windows и macOS — картинки, видео, 3D, материалы, шрифты, PDF и PSD;
поиск по цвету и по смыслу, текст на картинках, увеличение картинок, 3D-просмотр и «SVG в 3D», конструктор иконок,
сценарии из записи экрана, командная библиотека, лента новостей, плагины Blender и Figma, расширение для браузеров,
MCP для Claude.
