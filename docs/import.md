# Переезд из Eagle и PureRef

Oddments копирует файлы к себе и ничего не меняет в исходной библиотеке: Eagle и PureRef можно оставить как есть.

## Eagle

**Добавить › «Перенести из Eagle…»** (или в палитре команд, или галкой в окне первого запуска) → выберите папку
библиотеки Eagle — ту, что кончается на `.library`. Где она лежит, показывает сам Eagle: «Библиотека › Показать в
проводнике / Finder». Перед переносом лучше закрыть Eagle.

Что переносится:

| В Eagle | В Oddments |
|---|---|
| Папки и вложенные папки | подборки внутри подборки «Eagle · имя библиотеки» |
| Файл | оригинал копируется, превью Oddments делает заново |
| Имя, теги | имя, теги |
| Аннотация и комментарии на картинке | заметка |
| Ссылка (URL) | ссылка на источник |
| Дата добавления | дата добавления |
| Файлы без папки | подборка «Eagle · имя библиотеки» |

Не переносятся: корзина Eagle, оценки-звёзды (в Oddments нет рейтингов), умные папки, цветовые группы тегов, пароли
папок. Палитру Oddments считает сам.

Повторный перенос той же библиотеки добавит только то, чего ещё нет: Oddments помнит, какие файлы уже пришли из Eagle.
Большая библиотека переносится не мгновенно — прогресс виден в плашке сверху, Oddments в это время работает.

## PureRef

**Добавить › «Картинки с доски PureRef…»** → выберите один или несколько файлов `.pur`. Каждая доска становится
подборкой «PureRef · имя доски» с картинками из неё.

Формат `.pur` закрытый, поэтому Oddments берёт из него только сами картинки — они хранятся внутри целыми файлами.
Расположение, масштаб, повороты, обрезка и текстовые заметки на доске не переносятся. Одна и та же картинка, положенная
на доску несколько раз, придёт один раз. Если доска сохранена версией PureRef, которую Oddments не читает, он скажет,
что картинок не нашлось, — тогда можно выделить картинки в PureRef, скопировать (Ctrl/⌘+C) и вставить в Oddments.

## Обычные папки

Добавить › «Импортировать папку» — все файлы из папки и подпапок, любые форматы, которые Oddments умеет показывать.
