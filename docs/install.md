# Как поставить Oddments

Установщики — на странице [Releases](https://github.com/peopleskynet-boop/Oddments/releases). Пока сборки не подписаны
сертификатом разработчика, система при первом запуске переспросит — это нормально, один раз.

## Windows 10 и 11

1. Скачайте и запустите `Oddments_…_x64-setup.exe`. Установка — для текущего пользователя, права администратора не нужны.
2. Если Windows покажет «Система Windows защитила ваш компьютер»: **«Подробнее» → «Выполнить в любом случае»**.
3. WebView2 уже есть в Windows 11 и свежей Windows 10; если его нет, установщик поставит сам.

## Mac (Apple Silicon и Intel, macOS 11 и новее)

1. Откройте `Oddments_…_universal.dmg` и перетащите **Oddments** в **Программы**.
2. В **Программах** нажмите на Oddments **правой кнопкой → «Открыть»** → в окне ещё раз **«Открыть»**.
   - Если кнопки «Открыть» нет (macOS 15 и новее): **Системные настройки → Конфиденциальность и безопасность** →
     внизу «Oddments заблокирован…» → **«Всё равно открыть»**, затем запустите Oddments снова.
   - Если пишет «Oddments повреждён»: в **Терминале** выполните
     `xattr -dr com.apple.quarantine /Applications/Oddments.app` и запустите снова.
3. Дальше Oddments открывается как обычно.

На Mac нет «Ремеша» через AutoRemesher (у него нет версии для Mac); «SVG в 3D» работает в режиме «Точная».
Палитра команд — **⌘ K**.

## Первый запуск

Oddments спросит:
- **язык** — русский или английский (потом: Настройки › Вид › Язык);
- **папку библиотеки** — по умолчанию `Документы/Oddments Library`; можно выбрать папку в облаке или на сетевом диске;
- **перенести ли файлы из Eagle** — сразу после запуска откроется выбор папки `.library` ([import.md](import.md));
- **что включить**: поиск по смыслу (модель ~0,9 ГБ скачается один раз), текст на картинках (13 МБ), проверку
  обновлений, режим «Без сети».

Слева внизу появится «Знакомство» — пять коротких шагов по главному. Клавиши — по **?**.

## С чего начать

- Перетащите в окно картинки, видео, модели или нажмите **Ctrl/⌘ + V** — Oddments сам сделает превью.
- **/** — поиск, **[** — левая панель, **\\** — чистый экран, **?** — все клавиши.
- Библиотека — обычные файлы в выбранной папке, их можно забрать в любой момент.

## Обновления

Если проверка обновлений включена, раз в день Oddments спрашивает GitHub, нет ли новой версии, и показывает тост
«Есть новая версия» с кнопкой «Установить». На Windows установщик закроет и снова откроет Oddments сам; на Mac
приложение перезапустится. Проверить вручную — Настройки › О программе › «Проверить сейчас» или палитра команд.
Можно всегда скачать новый установщик со страницы Releases и поставить поверх — библиотека и настройки останутся.

## Аддон Blender

Проще всего — как расширение Blender 5.2 и новее, тогда обновления приходят в самом Blender:
1. Edit › Preferences › **Get Extensions** › меню **Repositories** (справа сверху) › **+** › **Add Remote Repository**.
2. URL: `https://github.com/peopleskynet-boop/Oddments/releases/latest/download/index.json`, галка **Check for Updates on Startup**.
3. Найдите **Oddments** в списке и нажмите **Install**.

Другой путь (и для старых версий Blender) — Oddments › «Плагины» › Blender › «Сохранить аддон…», затем в Blender
Edit › Preferences › Add-ons › Install from Disk. В обоих случаях вставьте токен из Oddments (Настройки › Интеграции ›
«Скопировать токен») в настройки аддона.

## Плагины и Claude

Все интеграции — в Oddments › левая панель › Инструменты › «Плагины»: Blender, Figma, Chrome и Edge, Safari и Claude.
Для Claude Desktop кнопка «Для Claude Desktop» копирует настройку — вставьте её в `claude_desktop_config.json`
(Claude › Settings › Developer › Edit Config) и перезапустите Claude. Для Claude Code — кнопка копирует команду
`claude mcp add …`. После этого можно просить Claude: «найди в Oddments референсы со стеклом и фиолетовым светом».

## Если что-то пошло не так

Настройки › О программе › «Отчёт о сбоях» › **«Скопировать отчёт»** — вставьте его в письмо
([peopleskynet@gmail.com](mailto:peopleskynet@gmail.com)) или в [Issues](https://github.com/peopleskynet-boop/Oddments/issues).
В отчёте версия, система и последние ошибки; имени пользователя и пути к библиотеке в нём нет.

## Как удалить

- **Windows:** Параметры › Приложения › Oddments › Удалить.
- **Mac:** перетащите Oddments из Программ в Корзину.

Библиотека при удалении остаётся на месте. Чтобы убрать и данные приложения (модели ИИ, настройки, отчёты), удалите
папку `%LOCALAPPDATA%\app.perch.desktop` (Windows) или `~/Library/Application Support/app.perch.desktop` (Mac).
